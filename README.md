# oddity-calendar

브라우저에서 바로 여는 달력이다. 파일은 `index.html` 하나이고, 서버나 설치가 필요 없다.

## 기능

- 월간, 주간, 일간 보기 (단축키 m / w / d, 오늘로 가기 t)
- 일정 만들기, 고치기, 지우기
- 캘린더 5개(내 일정, 가족, 주식, 한국 휴일, 미국 휴일)를 하나씩 켜고 끄기
- 일정 제목 검색
- 2026년 한국 공휴일 20일, 미국 공휴일 13일을 미리 넣어 두었다

## 쓰는 법

`index.html` 을 브라우저로 연다.

일정은 그 브라우저의 localStorage 에만 저장된다. 다른 기기나 다른 브라우저에서는 보이지 않는다.
