# oddity-calendar

브라우저에서 바로 여는 달력이다. 파일은 `index.html` 하나이고, 서버나 설치가 필요 없다.

## 기능

- 월간, 주간, 일간 보기 (단축키 m / w / d, 오늘로 가기 t)
- 일정 만들기, 고치기, 지우기
- 캘린더 5개(내 일정, 가족, 주식, 한국 휴일, 미국 휴일)를 하나씩 켜고 끄기
- 일정 제목 검색
- 2026년 한국 공휴일 20일, 미국 공휴일 13일을 미리 넣어 두었다

## 쓰는 법

`index.html` 을 브라우저로 연다.

이 달력에서만 만든 일정은 그 브라우저의 localStorage 에만 저장된다. 다른 기기에서도 보려면 구글 캘린더를 연결한다.

## 구글 캘린더 연결

연결하면 구글 캘린더의 일정을 불러오고, 구글 캘린더를 골라 만든 일정은 구글 서버에 바로 저장된다. 고치기와 지우기도 구글에 반영된다. 일정은 브라우저와 구글 사이에서만 오가고, 중간 서버는 없다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만들고 Google Calendar API 를 켠다.
2. OAuth 동의 화면을 만들고, 테스트 사용자에 본인 구글 계정을 넣는다.
3. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션을 만든다. 승인된 JavaScript 원본에 아래 두 주소를 넣는다.
   - `http://localhost:8765`
   - `https://destory1984.github.io`
4. 만든 클라이언트 ID(`….apps.googleusercontent.com`)를 `index.html` 의 `GOOGLE_CLIENT_ID` 에 넣거나, 처음 "구글 연결"을 누를 때 붙여 넣는다. 클라이언트 ID 는 공개되어도 되는 값이고, 클라이언트 비밀번호는 쓰지 않는다.

구글 로그인은 `file://` 로 연 파일에서는 동작하지 않는다. PC 에서는 아래처럼 로컬 서버로 연다.

```
python -m http.server 8765
```

그다음 `http://localhost:8765` 을 연다.

알아 둘 점

- 로그인 토큰은 1시간짜리이고 localStorage 에 둔다. 1시간 안에는 새로고침해도 다시 연결된다. 1시간이 지났으면 화면을 한 번 클릭할 때 새 토큰을 받는다(팝업이 잠깐 떴다 닫힌다).
- 보고 있는 달과 앞뒤 1달씩, 3달 치 일정을 불러온다.
- 이 달력의 일정에는 끝나는 시각이 없다. 새로 만든 구글 일정은 1시간짜리가 된다. 기존 구글 일정을 고치면 원래 길이를 지킨다(하루 안에 끝나는 일정일 때).
- 반복 일정은 하나씩 따로 보이고, 고치면 그 한 번만 바뀐다.
- "연결 끊기"를 누르면 구글에 토큰 취소를 요청하고, 저장한 토큰을 지운다. 구글 캘린더의 일정은 그대로 남는다.

## 사용한 글꼴과 그림

- 본문: [Pretendard](https://github.com/orioncactus/pretendard) 1.3.9, SIL OFL 1.1. jsDelivr CDN 으로 불러온다.
- 제목: [Gaegu](https://fonts.google.com/specimen/Gaegu), SIL OFL 1.1. Google Fonts 로 불러온다.
- `img/hop.png`, `img/banner.png`, `img/sleep.png`: ChatGPT 이미지 생성으로 그린 토끼다. 뛰는 그림 4장, 빈 현수막을 든 그림 1장, 조는 그림 1장이다. 현수막 글자("결혼 26주년 축하")는 그림이 아니라 HTML 글자로 얹었다. 토끼는 마우스를 따라오고 일정 칸은 피해서 다닌다. 멈추고 1.5초 뒤에는 현수막을 들고 흔든다. 조는 모습은 지금은 꺼 두었다.
- 현수막이 올라가면 이즈라엘 카마카위올레의 「Somewhere over the Rainbow」가 흐른다. 음원을 저장소에 두지 않고, 권리자(Mountain Apple Company)가 유튜브에 올린 공식 영상을 오른쪽 아래 작은 플레이어로 끼워 넣어 튼다. 토끼가 다시 뛰면 멈추고, 현수막을 다시 들면 이어서 튼다.
- 유튜브를 불러오지 못하면 Web Audio 로 만든 짧은 오르골 소리(멘델스존 「결혼 행진곡」 첫머리의 팡파르를 본뜬 소절)가 대신 울린다.
- 위쪽 스피커 단추로 소리를 켜고 끈다. 아이콘(`img/ui/icon-sound-on.svg`, `icon-sound-off.svg`)은 같은 사람의 oddity 프로젝트에서 가져왔다(MIT). 브라우저 규칙상 페이지를 한 번 클릭한 뒤부터 소리가 난다.
